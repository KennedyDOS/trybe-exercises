## Buscando dados em um banco de dados.

Nesse contéudo comecei a compreender o que é uma query SQL e seus comandos como SELECT, CONCAT, DISTINCT, COUNT, LIMIT/LIMIT OFFSET E ORDER BY. 
Com eles aprendi a pesquisar e retornar dados, juntar colunas, evitar repetições na query e limitar a quantidade de valores retornados, além de ordernar os dados de maneira crescente ou descrescente.
