## Filtrando dados

Nesse conteúdo aprendi a filtrar os resultados de consultas utilizando o comando WHERE, aplicando operadores booleanos (como AND, OR, NOT) e operadores relacionais (como =, >, <, >=, <=, <>) para refinar as buscas de dados. Criei consultas dinâmicas com o operador LIKE, permitindo a busca por padrões específicos em campos de texto.

Também explorei como limitar a faixa de resultados utilizando os operadores IN e BETWEEN, facilitando a seleção de múltiplos valores ou intervalos de dados específicos. Aprendi a separar e encontrar resultados com base em datas e horas, empregando funções de data e hora do SQL para realizar filtragens mais precisas e eficientes em conjuntos de dados temporais.
